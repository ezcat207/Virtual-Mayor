## 2. 丽水生态产品价值实现数字化
- GEP 核算：2025 年起标准化 GEP 核算模型上线，目标"任一区域 GEP 一键核算、一键报告"（来源为目标表述，是否全面运行需核实 [存疑]）。
- 信息云平台、生态产品交易平台（2025 年交易额 79.66 亿）、"丽水山耕"研发平台与核心产品库、区块链用于碳汇确权/质押/交易。
- 市长应追问：核算的遥感数据谁校验？GEP 贷与交易额里有多少是"真实新增"而非机构内部流转？

## 3. 数字政府与 AI+民生
- 浙里办是省平台，市级强项不在自建，而在接入与"最后一公里"（山区老年人、跨山办事）。
- 已有基础：知行大模型 + 政务知识库 + 智能体；缺口：对市民端的效果指标（办件时长、一次办成率、差错率）本次未见公开数据。

## 4. 关于"人民AI"
- 本次检索未找到任何关于丽水"人民AI"的**权威来源**。能核实的相关内容只有"人民数据"（人民网体系）与丽水共建数据要素联合实验室，以及"人民数据·城市词元工厂"平台。**"人民AI"作为产品或品牌在丽水的存在应标记为"无权威来源 / 待核实"。**（杭州 sources 同样将其列为缺口。）

## 5. 新市长须知
1. 丽水的 AI 战略是"应用与场景牵引 + 公共平台"，不是"模型研发"。别和杭州比拼大模型。
2. 数据要素还在"实验室 + 平台"阶段，没有看到交易规模；先问数据局"2025 年有多少数据产品真实成交"。
3. 半导体是当前最强的数字相关制造业，但依赖少数龙头与周期；重点关注水、电、人才与环保。
4. 最大风险：平台多、试点多，但缺少效果评估；以及 GEP 数字化的"数字漂亮、现金不足"。
5. 数据安全：政务环境部署 DeepSeek 与外部云的边界，要有审计与责任清单。

## 6. 有限预算下的小城市 AI 打法
1. **采购而非自研**：用省级与国家平台（浙里办、省政务大模型、国家数据局资源），本地只做场景适配。
2. **券补代替补贴**：AI 创新券（算力、API、数据集）以按使用量付费，设单企业上限与效果回收。
3. **先做高频、高回报场景**：涉企问题闭环（丽企宝）、环评/审批智能体、基层治理问答、农产品溯源、景区客流预测，一年内可测算节省工时。
4. **用共建换资源**：与运营商、产投集团、人民数据联合实验室共担成本；要求开放 API 与数据可迁移，避免被锁定。
5. **指标先行**：每个 AI 项目上线前定义基线（办件时长、满意度、差错率、节省人天），一年内不达标则下线。
6. **能力建设**：对县乡干部培训（市里已开展"人工智能赋能传统产业技能服务团"），在山区县设"AI 联络员"，而不是重复建设。
7. **治理底线**：采购合同中写入数据归属、模型更换权、事故责任；对老年人保留人工通道。
